### 📖 Projeto principal

#### [CadernoIA](https://github.com/wenderson-hgs/cadernoia)
> Tirou a foto da questão → recebe a resposta, ajustada ao espaço do caderno.
> Leitura automática: OCR da pergunta, medição do espaço livre e da letra.

**Next.js 16 · React 19 · Tailwind CSS v4 · IA plugável (mock/OpenAI)**
